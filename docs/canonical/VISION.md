# Francis Vision

Francis is a local-first, policy-guarded, auditable autonomous colleague that ships working outcomes fast.

## Principles
- Safety and governance first
- Auditability by default
- Ship now, iterate with real usage
- Simple over clever
- Graceful degradation when dependencies are missing

## Boundaries
- No network access without explicit approval
- No destructive actions without explicit approval
- Preserve historical logs and evidence
- Respect privacy and workspace constraints

## System Pillars
- Kernel + scheduler for orchestration
- Governance and trust gates for action readiness
- Memory and continuity for long-lived context
- LLM routing and guardrails for safe reasoning
- API/CLI for integration and operations
- Plugins/specializations for extensibility

## Near-Term Priorities
- Stabilize core flows and integrations
- Expand playbooks and recovery tooling
- Strengthen evaluation coverage for reliability and recovery
